Database Tester

Use this page to try SQL commands, see the JSON response, and understand how the connector works.

How the database connector works

The browser does not connect to MySQL directly. Instead, js/runQuery.js sends your SQL command to dbConnector.php using a POST request. The PHP script reads the query, connects to the database with the server-side host, username, password, and database values, then runs the query and returns JSON.

  • You type an SQL statement into the box below.
  • runQuery.js sends the statement to dbConnector.php.
  • dbConnector.php uses the configured host and credentials to open the database connection.
  • The query runs on the server, and the result is returned as JSON.
  • SELECT queries return a data array, while action queries return affected_rows.
The host value is handled inside dbConnector.php, so users only need to enter SQL here. This keeps the database credentials hidden from the browser while still allowing query testing.

JavaScript examples explained

Each part of the tester uses a small piece of JavaScript. The examples below show what each piece does so the page is easier to follow.

  1. Example 1: Sample buttons fill the query box. When you click a sample button, the script reads the button's data-sample value and copies it into the textarea. 
    button.addEventListener("click", () => {
			sqlInput.value = button.dataset.sample;
			});
  2. Example 2: The form runs the query. When you click a sample command like SELECT * FROM Report LIMIT 5;, it is placed into the textarea. Submitting the form then reads that SQL from the box and passes it into the helper. 
    queryForm.addEventListener("submit", async (event) => {
			event.preventDefault();
							const sql = sqlInput.value.trim();
							await runCurrentQuery();
			});
  3. Example 3: The helper sends the SQL to PHP. The helper takes the SQL from the textarea and passes it into runQuery(sql). For example, if the box contains runQuery("SELECT * FROM Report LIMIT 5;"), that SQL string is sent to dbConnector.php by js/runQuery.js. 
    async function runCurrentQuery() {
							const sql = sqlInput.value.trim();
							const result = await runQuery(sql);
							}
  4. Example 4: The response is shown on the page. If JSON comes back with rows, the script prints the raw JSON and also builds a table from the returned data.

What to expect from the JSON response

A successful SELECT query returns an object like { success: true, data: [...] }. A query that changes data returns { success: true, affected_rows: n }. If something goes wrong, the response includes an error message that can help you debug the SQL.
